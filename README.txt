THE LAST SHIFT — WEBSITE

This is the first static website for THE LAST SHIFT.

FILES
- index.html
- style.css
- script.js

HOW TO USE
1. Open index.html in a browser to preview the site.
2. When you have a packaged Windows build of the game, upload it to your chosen file host.
3. In index.html, find:
   <a class="download big" href="#" onclick="downloadPlaceholder(event)">
4. Replace the # with the download URL.
5. Remove onclick="downloadPlaceholder(event)" from that same link.

The site is static, so it can be hosted on many free static hosting services.
